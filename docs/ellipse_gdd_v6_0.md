# Эллипс — Game Design Document v6.0

**Дата:** 2026-08-01  
**Статус:** контракт текущей итерации разработки  
**Область:** главное меню, переназначение управления и изолированная Комната разработчика для полного набора Резонаторов и Резонансов

---

## 1. Приоритет и границы

GDD v6.0 дополняет v5.0 только в пределах перечисленных систем. Боевой маршрут Старого Шлюза, его комнаты, баланс, сюжет и progression заморожены до завершения всех типов Резонаторов и Резонансов.

Существующая игра остаётся доступна через пункт «Новая игра» и не используется как полигон разработки новых цветовых механик.

## 2. Главное меню

При запуске открывается отдельное главное меню:

1. Новая игра;
2. Комната разработчика;
3. Настройки;
4. Выход.

Фон меню использует runtime-копию `artbook/Ellipsis.png` с сохранением пропорций. Меню поддерживает RU/EN, мышь, клавиатуру, геймпад и touch.

«Новая игра» загружает существующий Старый Шлюз без изменения его механик. «Комната разработчика» загружает отдельную сцену. «Настройки» открывают общий экран настроек. «Выход» завершает приложение.

## 3. Переназначение управления

Настройки позволяют изменять gameplay- и developer-actions во время тестирования.

Обязательные правила:

- новый ввод применяется без перезапуска;
- назначения сохраняются в `user://settings.cfg`;
- поддерживаются клавиатура, мышь и геймпад;
- конфликт назначений явно показывается до замены;
- доступен сброс к значениям по умолчанию;
- HUD и tutorial получают фактические назначения из Input Map;
- экранная кнопка меню остаётся безопасным способом открыть настройки.

Debug-команды основной кампании не показываются в пользовательском списке.

## 4. Цветовая цепочка

Семь цветов образуют линейную последовательность:

> `Ф → С → Г → З → Ж → G → К`

Где `G` — латинское обозначение Золотого, а `З` — кириллическое обозначение Зелёного.

Резонанс возникает:

- между двумя Волнами одного цвета;
- между Волнами соседних цветов.

Несоседние цвета не Резонируют. Цепочка не замыкается: `К/Ф` не существует.

## 5. Три типа Резонаторов

| Тип фронта | Цвета |
|---|---|
| Круговой | Фиолетовый, Синий, Голубой, Красный |
| Архимедова спираль | Зелёный |
| Прямой однонаправленный | Жёлтый, Золотой |

Цвет определяет принадлежность источника и Волны. Геометрический тип определяет форму фронта и способ вычисления пересечений.

Ковырялка условно серая, но не является восьмым цветовым Резонатором. Она только Поглощает фронт и создаёт safe gap.

## 6. Полный набор Резонансов

### 6.1. Одноцветные

1. `Ф/Ф` — Лиссажу 2:1;
2. `С/С` — рёбра Делоне;
3. `Г/Г` — шестилепестковая розетка;
4. `З/З` — листья Гиелиса;
5. `Ж/Ж` — последовательное заполнение сектора;
6. `G/G` — движущаяся плитка Пенроуза;
7. `К/К` — динамический Вороной с guard-ring.

### 6.2. Соседние смешанные

1. `Ф/С` — проекция Лиссажу 2:1;
2. `С/Г` — описанные окружности Делоне;
3. `Г/З` — радиальный Фурье;
4. `З/Ж` — ветвящиеся кусты;
5. `Ж/G` — равномерная ромбическая сетка;
6. `G/К` — гирлянда инфляционных звёзд.

Итого зафиксировано `7 + 6 = 13` типов.

Точные математические и визуальные источники задаются `ellipse_resonances_color_math_contract_v1.md` и комплектом `ellipse_resonances_exact_restore_v1_bundle`.

## 7. Комната разработчика

Комната разработчика является самостоятельным тестовым окружением и не входит в dungeon sequence.

Она должна позволять:

- выбрать любой из семи цветов;
- поставить до пяти Резонаторов в любой комбинации;
- повторять цвета;
- синхронно запускать Волны;
- удалить последний Резонатор;
- очистить тестовое поле;
- наблюдать типы, реальные пересечения и стадии Резонансов;
- менять скорость симуляции и приостанавливать её;
- вернуться в главное меню.

При попытке поставить шестой Резонатор применяется FIFO: удаляется самый старый экземпляр.

## 8. Архитектурная изоляция

- Dev Room не изменяет `EncounterCatalog` и последовательность Старого Шлюза.
- Новые цветовые Волны и Резонансы реализуются через отдельные data-driven системы.
- Основная игра не получает новые механики до отдельного решения после завершения 6.0.
- Общими остаются только настройки, Input Map, аудиоинфраструктура и базовые визуальные контракты.

## 9. Критерии завершения

Версия 6.0 завершена, когда:

- главное меню полностью функционально;
- назначения управления меняются и сохраняются;
- в Dev Room доступны семь цветов и три геометрических типа;
- одновременно существуют не более пяти Резонаторов;
- реализованы все 13 допустимых Резонансов;
- несоседние пары не создают Резонанс;
- узлы следуют реальным движущимся пересечениям;
- исходники, GIF и snapshots остаются воспроизводимым эталоном;
- существующие smoke-тесты Старого Шлюза проходят без изменения ожидаемого поведения.
