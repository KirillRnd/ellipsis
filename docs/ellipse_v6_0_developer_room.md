# Эллипс 6.0 — Комната разработчика

Комната разработчика запускается из нового главного меню и не входит в маршрут Старого Шлюза.

## Быстрый цикл тестирования

1. Выберите один из семи цветов в левой панели.
2. Наведите курсор на арену и поставьте Резонатор действием `place_resonator` (`E` по умолчанию).
3. Повторите для нужной комбинации, максимум — пять источников.
4. Запустите синхронный залп действием `resonator_volley` (ПКМ по умолчанию).
5. Используйте паузу и изменение скорости для чтения пересечений и стадий.

Шестая постановка удаляет самый старый Резонатор и его активные Волны.

## Действия по умолчанию

| Действие | Ввод |
|---|---|
| Поставить Резонатор | `E` |
| Синхронный залп | ПКМ |
| Предыдущий / следующий цвет | `Q` / `F` |
| Удалить последний | `X` |
| Очистить полигон | `C` |
| Пауза симуляции | `T` |
| Медленнее / быстрее | `-` / `+` |

Все эти действия доступны в экране переназначения управления. Изменения применяются сразу и сохраняются в `user://settings.cfg`.

## Диагностика

Левая панель показывает:

- число Резонаторов из пяти;
- число активных Волн;
- число текущих геометрических узлов;
- идентификаторы активных Резонансов;
- время вычисления геометрии текущего кадра.

Допустимы только семь одноцветных и шесть соседних смешанных пар. Несоседние цвета могут пересекаться визуально, но Резонанса не создают.

## Ручная приёмка Резонансов

Подтверждено на состоянии ветки `2ef1e1e`:

- `Ж/G` — правильная ромбическая сетка, включая повторные одиночные залпы;
- `G/G` — правильная условно бесконечная движущаяся плитка Пенроуза.

Эти реализации считаются контрольной точкой и не должны меняться при исправлении остальных Резонансов.

## Проверка без запуска Godot

```powershell
python tools/verify_v6_static.py
```

Проверка контролирует состав цветовой матрицы, три геометрии, все эталонные генераторы/GIF/snapshots, Input Map, сцены и фон меню.
